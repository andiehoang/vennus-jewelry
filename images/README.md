# Images

Put your product photos, hero images, and video files in this folder.

See the "Adding your own images and video" section in the main README.md (in the project root) for exactly how to wire a file placed here into the site.

Suggested sizes:
- Hero (home / maison): 1920×1080px (or a short looping video)
- Editorial split images: 1000×1200px
- Product photos: square or 4:5 portrait, at least 1200px on the long edge
- Mega-menu feature images: 500×400px
